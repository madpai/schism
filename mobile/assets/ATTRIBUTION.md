# SCHISM asset credits

Seventeen original generated raster assets: built-in image_gen.imagegen; prompts, original output hashes and source identifiers in ../art/provenance.json and ../art/living-city-provenance.json. No game screenshots or commercial game assets used as input. Raster object atlas, scene state variants and backpack close-up use the project’s original scene art as references. Native atlas regions, compositing shaders and animations are authored in this project. The Living City corridor uses the original street as a style reference; the replacement object sheet uses an original text prompt. Original outputs are retained unchanged; individually authored source regions and a <=16/255 alpha cutoff isolate each complete item.

Original audio synthesis: ../art/synthesize_audio.py and audio-provenance.json. Synthesized audio is original project material; distribution follows the repository owner’s license. No third-party sound samples.

The original municipal clipboard artwork and generation prompt/hash are recorded in `art/paperwork-provenance.json`. Its source pixels are preserved; live form text, checkmarks and signatures are game presentation.
