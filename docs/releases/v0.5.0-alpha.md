SCHISM 0.5.0 makes work hands-on and civic paperwork physical.

- Laundry requires individual loading, collection and folding on every shift. Familiar-work auto-completion is removed, including from command authority.
- Dragging clothing holds the interaction sheet still; releasing restores scrolling. Large tap alternatives remain.
- Available jobs appear on a painted municipal clipboard. Check one vacancy, then sign to authorize employment. Unsigned selections do not change your job.
- Illustrated paperwork extends to residency, taxes, tenancy, wage receipts, freight manifests and correction records. Home and sanitation interactions gain close-ups from the original paintings.
- Existing environments, washer animation, backpack, survival economy, manual three-day taxes and player-directed service repairs are preserved.

Install **schism-0.5.0.apk over the existing app** to retain your citizen. Do not uninstall. Package `org.schism.districtix`, version code 5, retained signer, save schema 6. Android 7.0 / API 24+, arm64 and x86_64. This is a development prerelease.

Validation: 1,987 headless checks, ordinary survival balance, asset provenance, headless import and Android/Linux exports. Android emulator evidence and precise coverage are in `docs/playtests/ANDROID_V050.md`. No physical-phone testing is claimed. Signing uses a simple tap rather than freehand handwriting; broader artwork and phone ergonomics remain future work.

The three attached files contain the APK, package manifest and SHA-256 checksums. Source prompts and original artwork provenance remain in the repository.
