# Phase 0: browser prototype audit

Source: clean main 0ba675e, v0.10. Git remote matches madpai/schism; fetch shows no newer main. Browser code, migrations, 39 embedded art assets and tests retained in place. Old README, architecture, rules and handoff copied to docs/legacy. File hashes in inventory-v010.json; this inventory records the audit snapshot, not a new release manifest.

The vanilla DOM UI has 17+ navigation screens with button-based timed actions. public/app.js composes pages; character/residency/home/street/life/workbench render interlocking dashboards. CSS has terminal/noir/occult layers. Painted cinematic backgrounds and assembled portrait layers are valuable provenance examples but visually incompatible with the new PSX camera/texture language.

worker/game.js is the D1 transaction authority, world and action orchestrator. residency handles registration, six-hour clock, taxes, ID holds and deferred activity. progression handles careers, rank, gear and shift quotes. workshop adds unique device escrow, skill practice, restricted drugs and finite camp. living protects fallback shelter and bounded rent. orders conserves funded escrow and taxable seller proceeds. citylife/crises/aftermath derive immutable contributions, fixed targets and bounded district pressure; tenants conserves shared stock/capacity and exact protection windows. life/stories/contacts/neighborhood store branching histories. community handles trusted operator identity, rate limits, reports and backup exports. reset is an explicit idempotent historical reset, not an upgrade path. index trusts Sites-provided identity, validates API size/type/origin and redacts operational failures.

Drizzle has ten append-only migrations and 30 tables. Source stores citizen JSON with optimistic version, action guards with rollback, mutable shared stock and immutable commitments. Local adapter uses Node experimental SQLite; hosted identity/D1 differ from local signed-cookie QA. Build embeds interface/art into one Worker. .openai references the existing private Site; publishing is unrelated to the Android request. Live local city runs from the separate ashfall checkout and must remain untouched.

Reuse concepts: tax fraction carry, guarded resource conservation, exact completion boundaries, additive awards, private record versus shared output, unique ownership/history, version migration, safe backup restore, bounded rent and exact camp billing pause, fixture-driven rule tests. Reuse lore: civic identity, District IX, industrial work, municipal fallback, institutional suspicion, forgotten devices and repair as modest advancement.

Retire from active mobile presentation: six-hour shared-day offline survival decay, real 15–90 minute action timers, overt supernatural opening descriptions, faction rites, simultaneous career trees, extensive visible stats, generic crime operations, dozens of screens and large NPC thread cast. Do not port old data just because it exists.

Baseline Node tests run on isolated in-memory fixtures. New native tests use deterministic commands and isolated save directories. No running city, private backup or citizen was used as a fixture. Node dependency audit reports existing moderate development dependency findings; mobile has no Node runtime dependency.
